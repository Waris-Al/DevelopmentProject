# DevelopmentProject

This repository contains the code for my Development Project
<br>
It is a website that will allow its users to track what albums they have listened to and being able to write their own reviews. The user will have a diary that shows the date they listened, and their overall review. They can also see the diaries of others, as well as comment on another’s review. Users will be able to see all reviews (by other users) of an album by searching for it as well. Based on a user’s reviews, the system should be able to suggest other albums they may enjoy. It should also give recommendations on reviewers to follow this way.
